# Immigration rules reference

Checklists of student-visa/immigration rules for destination countries, organized by region.
These are **reference material**, independent of anything an agency posts on social media —
use them to fact-check agency claims, not the other way around.

- `europe/` — united_kingdom.md, ireland.md, germany.md
- `asia/` — japan.md, south_korea.md, malaysia.md
- `australia/` — australia.md, new_zealand.md
- `north_america/` — united_states.md, canada.md

Every file starts from `_template.md`'s structure and carries a `last_verified` date. Fields
marked **TO VERIFY** are ones that change often enough (financial thresholds, work-hour caps,
post-study-work eligibility) that this project deliberately does not assert a specific figure
without a fresh check — confirm them against the official source listed at the bottom of each
file before using them to advise a student, especially given the target Jan/Apr 2027 intake is
still ahead of us and several of these countries (Canada, Australia, New Zealand, South Korea in
particular) have changed rules materially and repeatedly in recent years.

To add a new destination country: copy `_template.md` into the right region folder and fill it
in the same way.
